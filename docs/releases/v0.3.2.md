# Maré 0.3.2

- Windows installer with bundled, signature-checked WebView2 bootstrapper, automatic runtime detection and desktop/Start menu shortcuts. Internet is needed to install WebView2 if absent.
- Native Save As selection, original download names, byte progress, cancellation, resumable engine transfers and useful failure reasons. Previously downloaded files remain in their original folder.
- Rust audio decoding with Rodio/Symphonia, a dedicated WASAPI audio thread and multimedia scheduling priority.
- Playlist pages with public track metadata, downloaded status and per-track play availability. Standalone tracks are grouped under Músicas baixadas.
- Compact expandable download activity, with real completed-track progress. The last completed track is identified explicitly; the original Sunnify CLI does not expose a reliable currently-downloading track event.
- Listening activity with artist display preference, track title and available cover art.
- Embedded chat window ordering and opacity fixes in the local adapted client, with no standalone update UI.
- Website favicons and executable icon resources.
- YouTube-specific player-response filtering and cosmetic controls, respecting Shield exceptions. This is additional best-effort coverage, not feature parity with Brave Shields.

The public installer includes the original unmodified Sunnify CLI under its own terms. The locally adapted larperCord binary is not redistributed while its principal source license remains undefined. The browser installer does not require Rust, Python or a separate manual WebView2 download. Spotify account import still needs a maintainer Client ID; public playlist metadata and local audio work without connecting an account.
