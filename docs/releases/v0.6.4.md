# Compass Browser 0.6.4

Adds the missing browser-to-desktop handoff for Riot Client sign-in.

- Riot HTTPS authentication pages can request their registered `riotclient:` callback through WebView2's external-URI API, including redirect and popup flows.
- Compass asks **Open Riot Client?** before passing the callback to Windows. Permission is one-shot, expires after two minutes and is cleared when the tab navigates or closes.
- Only Riot HTTPS origins can request this handoff. Executable, file, system-settings and unrelated external protocols remain blocked.
- Callback values stay in host memory; the browser's permission UI and navigation history do not receive callback tokens. No callback is launched without approval.

Existing default-browser registration, profiles, logins and Noise Music features are preserved. Start a fresh sign-in from Riot Client after updating; an older login attempt may have expired.
