# Compass Browser 0.6.3

Compass can now receive HTTP/HTTPS links from other Windows applications and appear in Windows Default apps.

- The installer registers Compass as a browser for the current Windows user. Choose Compass in Windows Settings to make it the default; the installer preserves the user's existing default selection.
- External links open in a new tab in the existing Compass instance. A per-profile exclusive lock prevents concurrent browser processes from overwriting the same session. Link delivery stays on loopback and requires a private, randomly generated nonce; link URLs are never written to the IPC metadata file.
- External launch accepts HTTP/HTTPS only, preserves OAuth query strings and rejects executable/internal URL schemes.
- Existing Noise Music streaming, account playlists, listening rooms and browser profile data are retained.

Google can restrict OAuth in embedded web engines. Setting Compass as default does not override a provider's authentication policy. If a provider rejects this engine, use a supported external browser for that sign-in.
