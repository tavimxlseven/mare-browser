# Compass Browser 0.5.6

Maré Browser is now **Compass Browser**. Its music app is now **Noise Music**, with new compass and headphones artwork across Windows, Android and the webapp.

- Existing profiles, browser sessions, logins, music libraries and Android application identity are retained. Internal executable/package names stay compatible with existing installations and the updater.
- Public Spotify playlists can refresh into Noise Music every 30 minutes, with manual refresh and per-playlist opt-out. Custom names, artwork and manual additions remain intact. Spotify itself is never modified.
- Finished preparation activities expire correctly when the audio source is paused. Redundant cards are archived; dismissing an activity preserves its preparation queue.
- Administrators can securely replace the YouTube session file inside Noise Music settings. Cookie contents never appear in API responses or public source. Automatic Google/YouTube login renewal is not supported.

The Windows setup includes the WebView2 bootstrapper. Its filename remains `Mare-Setup-0.5.6-x64.exe` for compatibility with older automatic updaters.

Android branding is available separately in Noise Music 0.3.1. Existing Android accounts and downloads remain on the device when updating the APK in place.
