# Compass Browser 0.6.0

Noise Music on Windows now supports server streaming and private shared listening.

- Play the playlists synchronized from your phone without downloading the entire playlist to your PC. Existing local audio is preferred; offline downloads remain optional.
- Tracks already prepared on the server can stream immediately. Other tracks enter the existing preparation queue, with duplicate work prevented and playback requests cancellable when you select another song.
- The music toolbar includes **Listen together**. Create a room, share its invitation code yourself, and listen with friends signed into separate accounts on the same server. The creator controls playback, while each participant keeps independent volume.
- Shared playback follows play/pause, seeking and track changes, corrects drift, and pauses when the creator disconnects. Leaving the room stops the participant's shared audio.
- Streaming uses short-lived, track-scoped access grants. Long-lived account tokens remain protected by Windows; participants do not receive access to the creator's full library.
- Queue restoration, saved position, volume, device control and Discord Rich Presence also work with streamed tracks. Reopening the music app restores a paused session.

The server must be updated alongside this client. Existing browser profiles, music libraries, accounts and local downloads are preserved. The Windows setup includes the WebView2 bootstrapper.

See [streaming and shared listening](https://github.com/tavimxlseven/mare-browser/blob/main/docs/SHARED-LISTENING.md) for usage and server requirements.
