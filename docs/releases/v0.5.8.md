# Compass Browser 0.5.8

Fixes Noise Music downloads failing on Windows 10 when launched inside the browser.

- Windows canonical profile paths are converted to compatible DOS/UNC paths before they reach the bundled music tools. This fixes extractor startup failures caused by a verbatim path in the temporary-directory environment.
- Unicode filenames, UNC shares and the existing canonical containment checks are preserved. Profiles, accounts, playlists and downloaded audio keep their current locations.
- Playlist preparation checks whether the downloader can start before processing the batch. A broken installation now reports a component startup error instead of incorrectly reporting every song as unavailable.
- Adds regression coverage for canonical Windows worker paths.

The setup includes the WebView2 bootstrapper and the bundled download components.
