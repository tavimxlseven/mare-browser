# Compass Browser 0.5.7

Noise Music on Windows now keeps search artwork compact and handles temporary catalog outages more gracefully.

- Search rows use fixed 48-pixel artwork, separate title/artist information and grouped actions. Long titles truncate without pushing the controls off-screen.
- Transient catalog HTTP 500/502/503/504 responses receive one automatic retry. If the service remains unavailable, Noise can show results saved for that exact search or matching tracks from the local library, with a clear notice. Spotify track identities and artwork remain intact. The public catalog is an external service; availability is not guaranteed.
- Search metadata is cached privately in the current user's profile, with a seven-day lifetime and a 24-query limit.
- Desktop preparation searches across official audio, Topic and lyric uploads together, reuses compatible candidates and prepares up to three independent tracks at a time. Fragmented transfers can use four concurrent fragments. Source selection still checks artist, title and duration and retains the existing fallback for distributor aliases.
- Download events identify each track and include source lookup and completion timings, making slow lookup distinguishable from slow transfer.

Existing profiles, logins, music libraries and updater compatibility are preserved. The setup includes the WebView2 bootstrapper.
