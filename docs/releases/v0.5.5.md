# Maré 0.5.5

O navegador passa a guardar histórico, favoritos, sessões dos sites e dados dos apps em `%LOCALAPPDATA%\MareBrowser\User Data`, separado por usuário e instalação do Windows. A presença de outro disco não escolhe mais um perfil compartilhado. Atualizações seguintes mantêm essa pasta estável.

Se você usava o perfil antigo em `D:\MareBrowserData`, o setup oferece uma opção **desmarcada** para importar seus próprios dados para o usuário atual, somente quando o destino ainda não existe. A origem é preservada. Nenhum histórico de outro Windows é importado automaticamente. Cookies protegidos pelo Windows podem exigir nova autenticação. Feche o Maré antes de instalar.

O primeiro APK do Maré Música usa a interface da sua instalação com um player Android Media3: áudio, fila e troca de faixa ficam em um serviço de reprodução com notificação, separados da interface. Downloads de faixas preparadas usam armazenamento privado por servidor e conta. Informe seu servidor HTTPS e entre com a mesma conta do webapp. A instalação Android começa com um armazenamento próprio; downloads anteriores da PWA precisam ser salvos novamente.

O webapp continua disponível para iOS. O APK não depende das permissões de reprodução em segundo plano do navegador Android. A instalação por APK exige permitir instalação a partir do aplicativo usado para abri-lo. A versão inicial requer testes no aparelho físico; forçar a parada ou restrições do sistema ainda podem interromper serviços.

Instalador do PC: **Mare-Setup-0.5.5-x64.exe**. Aplicativo Android: **Mare-Musica-0.1.0.apk**.
