Maré 0.3.8 corrige a interface sem estilos que apareceu na versão 0.3.7.

A formatação do HTML alterou a tag do CSS, e o empacotamento antigo deixou de incluir os estilos. Esta versão usa marcadores explícitos para incorporar os recursos, com teste do HTML final para impedir a publicação sem CSS ou JavaScript.

Baixe **Mare-Setup-0.3.8-x64.exe**, feche o Maré e instale sobre a versão anterior. O perfil, a biblioteca e os dados dos sites são preservados. O redesign, wallpapers e sessão de reprodução continuam incluídos.
