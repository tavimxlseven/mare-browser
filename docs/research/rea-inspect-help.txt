rea inspect-desktop-application — Identify desktop runtime candidates from bounded directory and header observations

Usage: rea inspect-desktop-application <path> [options]

Arguments:
  path  Local installation directory

Options:
  --max_entries <number>       Maximum directory entries to examine; exhaustion leaves partial coverage (default: 20000)
  --detail <complete|summary>  Deliver complete Evidence, or a summary with --evidence_output (default: complete)
  --evidence_output <string>   Save complete Evidence as a bundle; required for summary delivery. Never overwrites.
  --max_probe_bytes <number>   Maximum total bytes read from selected file ranges (default: 8388608)

Global Options:
  --filter-output <keys>              Filter output by key paths (e.g. foo,bar.baz,a[0,3])
  --format <toon|json|yaml|md|jsonl>  Output format
  --full-output                       Show full output envelope
  --help                              Show help
  --llms, --llms-full                 Print LLM-readable manifest
  --schema                            Show JSON Schema for command
  --token-count                       Print token count of output (instead of output)
  --token-limit <n>                   Limit output to n tokens
  --token-offset <n>                  Skip first n tokens of output
