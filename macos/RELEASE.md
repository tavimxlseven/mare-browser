Noise Music para macOS é um aplicativo separado, com a interface e o motor de música
da edição para Windows. Links externos abrem no navegador padrão do Mac.

- Apple Silicon (M1 ou mais recente): use o ZIP `arm64`.
- Intel: use o ZIP `x64`.
- Requer macOS 13 ou mais recente. Extraia o ZIP e mova Noise Music para Aplicativos.
- Esta prévia usa assinatura local (ad hoc). Uma distribuição que abra normalmente
  via Gatekeeper depende de assinatura Developer ID e notarização.

A biblioteca fica em `~/Library/Application Support/Noise Music`. As credenciais
da conta Noise usam o Chaves do macOS.
